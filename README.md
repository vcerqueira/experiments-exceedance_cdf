# Exceedance Probability Forecasting for Wave Height Prediction

This repository contains the implementation and experimental framework for the paper:  
**"Exceedance probability forecasting via regression for significant wave height prediction"**.

The research focuses on predicting the probability that significant wave height will exceed certain critical thresholds, treating this task through a regression-based lens to improve maritime safety and coastal management.
